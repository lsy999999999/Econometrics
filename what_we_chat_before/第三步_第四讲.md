可以。下一步建议命名为 **Step 4：异方差诊断、稳健推断与效率改进**。这一部分正好对应第四讲的主线：在高斯—马尔可夫假定 1–4 下 OLS 是 BLUE，但社会经济数据中假定 4“同方差性”很容易不满足，因此要讨论异方差导致的问题、诊断方法和处理策略。第四讲明确把重点放在“异方差导致的问题—异方差的诊断—异方差的处理策略”这三块。

## 一、这一部分在我们论文里的定位

我们第三讲已经做的是：通过多元回归、控制变量、标准化系数、VIF、RESET、交互项等，把模型设定尽量做合理。第四讲不能再简单堆变量，而是要回答一个更“计量”的问题：

> 我们发现利率脆弱度越高的行业，在 FOMC 事件窗口内 CAR 越低；但这个结论会不会只是因为普通 OLS 标准误在异方差下失效？

所以 Step 4 的核心结论应该服务于论文主线：

> 即使允许不同行业组合具有不同的误差方差，利率脆弱度对事件窗口 CAR 的负向影响是否仍然稳健？

这很适合写进期末论文，因为大作业要求里明确要求对“模型可能存在的异方差问题”从实际问题角度和统计检验角度讨论，并给出解决策略。

---

## 二、第四讲知识点如何全部嵌入我们的实证

| 第四讲知识点           | 我们论文里怎么用                                           |
| ---------------- | -------------------------------------------------- |
| 高斯—马尔可夫假定 4：同方差性 | 说明事件研究截面回归中，不同行业的收益波动、流动性、估计误差不同，因此同方差很可能不成立       |
| 异方差导致的问题         | 强调异方差不一定改变 OLS 点估计，但会使普通标准误、t 检验、F 检验不可靠           |
| 异方差稳健标准误         | 报告 HC0、HC1、HC2、HC3，主表优先用 HC1 或 HC3                 |
| White/怀特稳健标准误    | 用 `sandwich::vcovHC()` 和 `lmtest::coeftest()`      |
| BP 检验            | 检验残差平方是否与解释变量相关                                    |
| White 检验         | 检验残差平方是否与解释变量、平方项、交乘项有关；样本小可用拟合值和拟合值平方的改进 White 检验 |
| WLS 加权最小二乘       | 用行业 CAR 的估计方差、预事件波动率、市场模型残差方差等构造权重                 |
| FGLS 可行 GLS      | 估计方差函数 `log(u_hat^2)`，得到 `h_hat` 后用 `1/h_hat` 加权   |
| FGLS 后再检验        | 检查变换后是否仍有异方差；若仍有，则使用稳健的 FGLS 标准误                   |
| 最终处理原则           | 主结论以 OLS + 异方差稳健标准误为主，WLS/FGLS 作为稳健性和效率改进          |

第四讲特别强调：稳健统计量是不放弃 OLS，而是改用异方差稳健标准误进行检验；但是否存在异方差仍然需要诊断。 同时，BP 检验和 White 检验的基本思路都是看残差平方是否可以被解释变量或其函数解释。 WLS/FGLS 则是在对误差方差结构有假定或能估计时，通过加权让变换后的模型更接近同方差。

## 三、具体实证计划

### Step 4.1 固定第三讲的基准模型

先不要继续换模型。我们要把第三讲最终版本作为第四讲的基础，例如：

[
CAR_i = \beta_0 + \beta_1 RateVulnerability_i + \gamma'Controls_i + u_i
]

其中：

* (CAR_i)：行业组合在 FOMC 事件窗口的累计异常收益；
* (RateVulnerability_i)：行业对利率冲击的脆弱度，建议继续用标准化版本；
* Controls：第三讲确定下来的控制变量，比如市场 beta、规模、账面市值比、动量、波动率、流动性或 Fama-French 因子暴露等。

这一部分的原则是：**第四讲不是重新定义因果问题，而是在第三讲模型基础上检验推断是否可靠。**

---

### Step 4.2 先写“为什么我们这里可能存在异方差”

这一段很重要，因为老师要求“从实际问题角度”讨论异方差。我们可以写：

在 FOMC 事件研究中，不同行业组合的收益波动程度、成分股数量、流动性、对宏观信息的敏感性并不相同。金融、房地产、耐用品等利率敏感行业在政策公告日前后可能具有更大的收益波动，而防御性行业的波动较小。因此，误差项方差可能随行业特征变化，即：

[
Var(u_i|X_i) \neq \sigma^2
]

这说明普通 OLS 的标准误可能不可靠，进而影响 t 检验、置信区间和联合显著性检验。

---

### Step 4.3 做残差图和直观诊断

先做图，不要一上来只给检验。建议输出 4 张图：

1. `Residuals vs Fitted`：看拟合值变大时残差是否呈扇形扩散；
2. `|Residuals| vs Fitted`：更直观看误差大小是否随拟合值变化；
3. `Residuals vs RateVulnerability_z`：看核心解释变量是否伴随更大波动；
4. 按利率脆弱度四分位分组，画每组残差方差柱状图。

这一部分能让论文更有说服力，不只是机械跑检验。

---

### Step 4.4 正式做 BP 检验

BP 检验对应第四讲“检验残差平方是否与一个或多个解释变量相关”的思路。原假设是同方差，若拒绝原假设，则说明存在异方差。

R 代码框架：

```r
library(lmtest)
library(sandwich)

m_base <- lm(CAR_3d ~ RateVulnerability_z + BetaMKT + logSize + BM + MOM + PreVol,
             data = cs_data)

# Breusch-Pagan 检验：默认使用模型右侧解释变量
bp_test <- bptest(m_base, studentize = TRUE)
bp_test
```

如果 BP 检验显著，我们写：

> BP 检验拒绝同方差原假设，说明模型残差方差与解释变量存在系统关系，普通 OLS 标准误可能不可靠。

如果不显著，也不能简单说完全没有异方差，而是说：

> BP 检验未能拒绝同方差原假设，但考虑到事件研究截面样本中行业波动存在差异，本文仍报告异方差稳健标准误作为稳健推断。

---

### Step 4.5 做 White 检验和改进 White 检验

White 检验比 BP 更一般，因为它允许残差平方与解释变量、平方项、交乘项有关。第四讲也指出，完整 White 检验参数很多，可以改用拟合值及其平方做改进版本。

我们样本大概率只有 49 个行业，完整 White 检验自由度消耗太大，所以建议主文使用“改进 White 检验”，附录可放完整版本。

```r
cs_data$fit_base <- fitted(m_base)

white_fitted <- bptest(
  m_base,
  varformula = ~ fit_base + I(fit_base^2),
  data = cs_data,
  studentize = TRUE
)

white_fitted
```

注意：这里你可以只做改进的怀特检验


如果要做完整 White 检验：

```r
white_full <- bptest(
  m_base,
  varformula = ~ (RateVulnerability_z + BetaMKT + logSize + BM + MOM + PreVol)^2 +
    I(RateVulnerability_z^2) + I(BetaMKT^2) + I(logSize^2) +
    I(BM^2) + I(MOM^2) + I(PreVol^2),
  data = cs_data,
  studentize = TRUE
)

white_full
```

主文建议写：

> 由于本文截面样本数量有限，完整 White 检验会引入大量平方项和交乘项，可能降低检验功效。因此本文同时报告基于拟合值及其平方的改进 White 检验。

这句话很体现模型意识。

---

### Step 4.6 报告 OLS 普通标准误与稳健标准误对比

第四讲强调：异方差稳健标准误在大样本下近似适用，且可用于异方差存在时的 t 检验。 我们这里样本不算大，所以建议至少报告 HC1 和 HC3。

```r
library(broom)
library(purrr)
library(dplyr)

se_types <- c("const", "HC0", "HC1", "HC2", "HC3")

robust_table <- map_dfr(se_types, function(tp) {
  if (tp == "const") {
    ct <- coeftest(m_base)
  } else {
    ct <- coeftest(m_base, vcov. = vcovHC(m_base, type = tp))
  }
  data.frame(
    se_type = tp,
    term = rownames(ct),
    estimate = ct[, 1],
    std_error = ct[, 2],
    t_value = ct[, 3],
    p_value = ct[, 4],
    row.names = NULL
  )
})

robust_table
```

主文重点看 `RateVulnerability_z`：

* 系数是否仍为负；
* HC1/HC3 下是否仍显著；
* 置信区间是否仍不跨 0；
* 与普通 OLS 标准误相比，显著性是否明显变化。

如果我们之前的结果是 HC1 下仍显著，那么第四讲这一部分可以成为强稳健性证据。

---

### Step 4.7 做稳健 Wald/F 检验

第三讲里我们用了联合显著性检验。第四讲之后，普通 F 检验在异方差下也可能不可靠，所以需要做“稳健联合检验”。

例如检验控制变量是否联合显著：

```r
library(car)

linearHypothesis(
  m_base,
  c("BetaMKT = 0", "logSize = 0", "BM = 0", "MOM = 0", "PreVol = 0"),
  vcov. = vcovHC(m_base, type = "HC3"),
  test = "F"
)
```

如果模型里有交互项，也可以稳健检验交互项是否联合显著：

```r
linearHypothesis(
  m_interact,
  c("RateVulnerability_z:HighDuration = 0",
    "RateVulnerability_z:HighLeverage = 0"),
  vcov. = vcovHC(m_interact, type = "HC3"),
  test = "F"
)
```

这一块能把第三讲的 F 检验和第四讲的稳健标准误连接起来。

---

### Step 4.8 做 WLS：有经济含义的加权最小二乘

WLS 的关键是权重。第四讲说，WLS 中误差方差越大，权重越小；如果 (h_i) 已知，可以用 (1/h_i) 加权。

我们这里最自然的权重有两个选择：

1. **基于估计窗口残差方差的权重**
   如果每个行业组合都有市场模型或因子模型估计窗口残差方差，可以设：
   [
   weight_i = \frac{1}{\widehat{Var}(CAR_i)}
   ]

2. **基于预事件收益波动率的权重**
   如果没有严格的 CAR 方差，就用事件前窗口收益方差：
   [
   weight_i = \frac{1}{PreEventVol_i^2}
   ]

R 框架：

```r
m_wls_var <- lm(
  CAR_3d ~ RateVulnerability_z + BetaMKT + logSize + BM + MOM + PreVol,
  data = cs_data,
  weights = 1 / CAR_var
)

coeftest(m_wls_var, vcov. = vcovHC(m_wls_var, type = "HC3"))
```

这里建议 **WLS 不作为主模型**，而作为稳健性检验。因为权重是否真实等于误差方差的倒数需要假设，主结论仍应基于 OLS + 稳健标准误。

---

### Step 4.9 做 FGLS：估计未知的方差函数

第四讲后半部分讲 FGLS：当 (h(x)) 未知时，可以先用 OLS 残差估计方差函数，再用 (1/\hat h_i) 作为权重做 WLS。

模型可以设：

[
log(\hat u_i^2) = \alpha_0 + \alpha_1 RateVulnerability_i + \alpha_2 PreVol_i + \alpha_3 logSize_i + e_i
]

然后：

[
\hat h_i = exp(\widehat{log(\hat u_i^2)})
]

R 框架：

```r
eps <- 1e-8
cs_data$u2_log <- log(resid(m_base)^2 + eps)

aux_var <- lm(u2_log ~ RateVulnerability_z + PreVol + logSize, data = cs_data)

cs_data$h_hat <- exp(fitted(aux_var))

m_fgls <- lm(
  CAR_3d ~ RateVulnerability_z + BetaMKT + logSize + BM + MOM + PreVol,
  data = cs_data,
  weights = 1 / h_hat
)

coeftest(m_fgls)
coeftest(m_fgls, vcov. = vcovHC(m_fgls, type = "HC3"))
```

注意：FGLS 的辅助方程不要放太多变量。我们样本只有几十个行业，方差函数放太多变量会过拟合。建议只放：

* `RateVulnerability_z`
* `PreVol`
* `logSize`

这三个有明确经济含义：利率脆弱度、原始波动率、组合规模/流动性。

---

### Step 4.10 FGLS 后再检验异方差是否被消除

第四讲里特别问：FGLS 处理后是否真的消除了异方差？如果没有，一般应采用稳健的 FGLS 标准误。 第四讲还总结说，若原模型同方差不成立且 (h(x)) 未知，通常应采用 FGLS，并一般采用稳健的 FGLS 标准误；如果变换后仍存在异方差，可能是 (h(x)) 函数形式设错。

```r
cs_data$fgls_fit <- fitted(m_fgls)

bptest(
  m_fgls,
  varformula = ~ fgls_fit + I(fgls_fit^2),
  data = cs_data,
  studentize = TRUE
)
```

如果仍显著，就写：

> FGLS 后异方差并未完全消除，说明设定的方差函数可能只能部分刻画误差方差结构。因此本文报告稳健 FGLS 标准误，并将 FGLS 作为稳健性检验而非替代基准模型。

这句话很关键，能体现你不是机械使用 FGLS，而是理解了它的条件。

## 六、我建议我们采用的最终判断规则

主结论以这个顺序判断：

1. **OLS + HC3 下核心系数仍为负且显著**：最理想，可以说结论稳健。
2. **OLS + HC3 下仍为负但显著性下降**：结论方向稳健，但统计证据变弱。
3. **WLS/FGLS 结果也为负**：说明结论不太受高波动行业影响。
4. **FGLS 后异方差仍存在**：不否定结论，但说明方差函数设定不完全，应采用稳健 FGLS 标准误。
5. **普通 SE 显著、稳健 SE 不显著**：不能再强说“显著影响”，应改成“方向符合预期，但统计证据依赖标准误设定”。
