对，第三讲这一层我们要做的不是“换一个更复杂的题”，而是把第二讲的一元截面回归升级成**多元截面回归**：从“利率脆弱度和行业CAR的简单相关”变成“在控制其他行业特征后，利率脆弱度对行业CAR的偏效应”。这正好对应第三讲的核心：当零条件均值假定可能因为遗漏变量而不满足时，对可观测的遗漏变量使用多元线性回归控制；第三讲也明确把内容分成多元回归必要性、参数含义、高斯—马尔可夫假定、变量重要性、模型设定、误设和诊断。

下面是我们进入第三讲后的详细执行计划。

# 0. 第三讲这一阶段的核心目标

第二讲我们做的是：

[
CAR_i=\beta_0+\beta_1RateVulnerability_i+u_i
]

现在第三讲要升级为：

[
CAR_i=\beta_0+\beta_1RateVulnerability_i+\gamma X_i+u_i
]

这里 (X_i) 是行业层面的可观测控制变量。核心问题变成：

> 在控制市场风险暴露、行业风格暴露、历史波动率和事件前动量后，行业利率脆弱度是否仍然能解释FOMC事件窗口收益？

也就是说，我们从“简单相关”进入“偏效应”。

你已经有的一元结果是很好的起点：利率脆弱度提高1个标准差，三日CAR平均下降约1.13个百分点，且HC1稳健标准误后仍显著。第三讲这一层要检验的是：这个结果是不是只是因为高利率脆弱度行业本身也是高市场beta、高成长风格、高波动行业。

# 1. 第三讲知识点一：为什么需要多元回归？

第三讲开头讲得很清楚：简单回归中假定3，也就是零条件均值假定，在社会经济问题中最容易不满足；重要原因之一是遗漏了与核心自变量相关的变量。讲义里的例子是免费午餐比例和数学成绩，直觉上可能遗漏了学生家庭贫困率、学校资源等因素，所以处理方法是把可测度的遗漏变量引入多元线性回归模型。

对应到我们的论文，一元模型里的误差项 (u_i) 至少可能包含这些东西：

| 可能遗漏因素          | 为什么会影响CAR                | 为什么可能和RateVulnerability相关 |
| --------------- | ------------------------ | ------------------------- |
| 市场beta          | 高beta行业在FOMC当天更容易随市场大幅波动 | 成长/周期行业通常也更利率敏感           |
| Fama-French风格暴露 | 行业收益可能由价值、规模、盈利、投资风格驱动   | 长久期行业往往成长属性更强             |
| 历史波动率           | 高波动行业事件日收益更极端            | 高波动行业可能更受利率冲击             |
| 事件前动量           | 事件前涨太多的行业可能回调            | 市场可能提前交易利率预期              |
| 行业类别            | 金融、科技、能源、公用事业机制不同        | 行业类别本身决定利率敏感性             |

所以我们在论文里可以这样写：

> 简单OLS模型中的 (\beta_1) 可能同时包含利率脆弱度本身的影响，以及市场风险暴露、行业风格、历史波动率和事件前趋势等遗漏因素的影响。为缓解可观测遗漏变量导致的估计偏误，本文进一步构建多元截面回归模型。

这句话就是第三讲的核心逻辑。

# 2. 第三讲数据表怎么扩展？

第二讲阶段我们的数据表大概是49行：

| industry | CAR | RateVulnerability |
| -------- | --: | ----------------: |

第三讲要扩成：

| 变量                    | 类型     | 构造方法                             | 对应第三讲作用    |
| --------------------- | ------ | -------------------------------- | ---------- |
| (CAR_i)               | 因变量    | FOMC事件窗口([-1,+1])行业累计收益          | 被解释变量      |
| (RateVulnerability_i) | 核心解释变量 | 事件前估计窗口内行业收益对(\Delta DGS2)的负向敏感度 | 关注的偏效应     |
| (MktBeta_i)           | 控制变量   | 事件前行业收益对市场因子的beta                | 控制市场风险     |
| (SMBBeta_i)           | 控制变量   | 行业对SMB因子的beta                    | 控制规模风格     |
| (HMLBeta_i)           | 控制变量   | 行业对HML因子的beta                    | 控制价值/成长风格  |
| (RMWBeta_i)           | 控制变量   | 行业对RMW因子的beta                    | 控制盈利能力风格   |
| (CMABeta_i)           | 控制变量   | 行业对CMA因子的beta                    | 控制投资风格     |
| (HistVol_i)           | 控制变量   | 事件前窗口日收益标准差                      | 控制风险/不确定性  |
| (PreMomentum_i)       | 控制变量   | 事件前([-60,-2])累计收益                | 控制提前交易     |
| (Group_i)             | 虚拟变量   | 科技、金融、能源、公用事业等行业组                | 做结构性变化/异质性 |

关键原则：**所有控制变量都必须用事件日前的数据构造**，不能用事件后的信息。这样可以避免“事后变量”污染解释。

# 3. 先估计行业特征：事件前窗口回归

我们可以用事件日前 ([-260,-30]) 个交易日作为估计窗口。对每个行业 (i)，估计：

[
R_{i,d}-R_{f,d}
===============

a_i
+b_{m,i}MKT_d
+b_{s,i}SMB_d
+b_{h,i}HML_d
+b_{r,i}RMW_d
+b_{c,i}CMA_d
+b_{rate,i}\Delta DGS2_d
+e_{i,d}
]

然后定义：

[
RateVulnerability_i=-\hat b_{rate,i}
]

这样解释更自然：

> (RateVulnerability_i) 越大，表示该行业历史上越容易在利率上升时下跌。

同时，(\hat b_{m,i},\hat b_{s,i},\hat b_{h,i},\hat b_{r,i},\hat b_{c,i}) 就是行业的市场beta和风格beta。这样我们的控制变量不是随便加的，而是有资产定价理论基础的。

---

# 4. 第三讲模型组：从简单到完整

## 模型0：第二讲基准模型

[
CAR_i=\beta_0+\beta_1RateVulnerability_i+u_i
]

这个模型保留，用来和后面多元模型比较。

解释重点：

> (\beta_1) 是未控制其他行业特征时，利率脆弱度与事件窗口收益之间的简单线性关系。

---

## 模型1：加入最基本控制变量

[
CAR_i
=====

\beta_0
+\beta_1RateVulnerability_i
+\gamma_1MktBeta_i
+\gamma_2HistVol_i
+\gamma_3PreMomentum_i
+u_i
]

这一版控制三个最基本的行业特征：市场风险、历史波动率和事件前趋势。

解释重点：

> 如果加入这些变量后 (\hat\beta_1) 仍然显著为负，说明一元模型结果不是单纯由高beta、高波动或事件前涨跌造成的。

---

## 模型2：加入Fama-French风格暴露

[
\begin{aligned}
CAR_i
=&\beta_0+\beta_1RateVulnerability_i+\gamma_1MktBeta_i+\gamma_2SMBBeta_i+\gamma_3HMLBeta_i\
&+\gamma_4RMWBeta_i+\gamma_5CMABeta_i+\gamma_6HistVol_i+\gamma_7PreMomentum_i+u_i
\end{aligned}
]

这是第三讲阶段的主模型。

它的意义是：

> 在控制行业常见风险因子暴露后，检验利率脆弱度是否仍有独立解释力。

第三讲强调多元回归系数的含义是在其他变量不变时，一个解释变量增加一单位引起因变量变化；并且要同时满足模型中其他变量不变和误差项中其他因素不变这两个条件。 所以我们在论文里解释 (\beta_1) 时一定要写成：

> 在控制市场beta、风格beta、历史波动率和事件前动量后，行业利率脆弱度提高一个标准差，事件窗口CAR平均变化多少个百分点。

不要再写成“利率脆弱度导致CAR下降”，而要写“在控制其他可观测行业特征后，利率脆弱度与CAR呈显著负相关；在本文识别框架下可理解为利率脆弱度的偏效应”。

---

# 5. 第三讲知识点二：用FWL思想解释“控制变量”

第三讲有一个很重要的思想：多元回归里的 (\beta_1) 可以理解为 (x_1) 扣除其他解释变量影响后的“净解释能力”。讲义用辅助回归说明，先把 (x_1) 对其他变量回归得到残差，再用 (y) 对这个残差回归，得到的就是 (x_1) 的偏效应。

我们可以在论文中加一个很漂亮的小解释：

对 (RateVulnerability_i) 做辅助回归：

[
RateVulnerability_i
===================

\pi_0+\pi_1MktBeta_i+\pi_2SMBBeta_i+\cdots+\pi_kPreMomentum_i+r_i
]

其中 (r_i) 是利率脆弱度中无法被市场beta、风格beta、波动率、动量解释的部分。

然后主回归中的 (\beta_1) 本质上度量的是：

> 行业利率脆弱度中“独立于其他风险暴露的部分”对FOMC事件窗口收益的解释力。

这会让老师感觉你真的理解了多元回归，而不是机械加变量。

R里可以做一个验证：

```r
aux <- lm(RateVulnerability_z ~ MktBeta_z + SMBBeta_z + HMLBeta_z +
            RMWBeta_z + CMABeta_z + HistVol_z + PreMomentum_z,
          data = df)

df$rv_resid <- resid(aux)

fwl <- lm(CAR ~ rv_resid, data = df)
full <- lm(CAR ~ RateVulnerability_z + MktBeta_z + SMBBeta_z + HMLBeta_z +
             RMWBeta_z + CMABeta_z + HistVol_z + PreMomentum_z,
           data = df)
```

理论上，`fwl`里面`rv_resid`的系数应该和`full`里面`RateVulnerability_z`的系数一致或非常接近。

---

# 6. 第三讲知识点三：高斯—马尔可夫假定在多元模型中的写法

第三讲把简单回归中的零条件均值扩展为：

[
E(u_i|x_{1i},x_{2i},...,x_{ki})=0
]

含义是：误差项与任何解释变量及其任何函数都无关；如果 (x_j) 与误差项不相关，它是外生解释变量；如果相关，它就是内生解释变量。

我们论文里可以专门写一小段：

> 本文多元模型的关键识别假定是，在控制市场风险暴露、风格暴露、历史波动率和事件前动量后，影响行业事件窗口收益的其他不可观测因素与行业利率脆弱度不系统相关。该假定比一元模型更弱，因为一部分原本进入误差项的可观测行业特征已经被显式控制；但它仍可能受到不可观测行业融资约束、现金流久期和事件日行业新闻的挑战。

这一段非常重要，因为它自然连接后面的第五讲“内生性”和第四讲“异方差”。

# 7. 第三讲知识点四：多重共线性诊断

第三讲讲了容忍度和VIF：解释变量之间共线性越强，估计量方差越大，估计结果越不稳定；通常VIF大于10或容忍度小于0.1可以认为多重共线性较强。

我们这一题很容易出现共线性，因为：

* (RateVulnerability) 可能和 (HMLBeta) 相关；
* 成长型行业可能同时具有低HML、高市场beta、高利率敏感性；
* RMW、CMA和HML之间也可能相关。

所以第三讲这一阶段必须做VIF表。

R代码：

```r
library(car)

m2 <- lm(CAR ~ RateVulnerability_z + MktBeta_z + SMBBeta_z + HMLBeta_z +
           RMWBeta_z + CMABeta_z + HistVol_z + PreMomentum_z,
         data = df)

vif(m2)
```

结果解释标准：

| VIF结果                       | 处理                                 |
| --------------------------- | ---------------------------------- |
| 所有VIF < 5                   | 共线性问题较轻，可以保留完整模型                   |
| 有变量VIF在5—10                 | 报告并谨慎解释                            |
| 有变量VIF > 10                 | 做精简模型，删除非核心且高度共线变量                 |
| 核心变量RateVulnerability VIF很高 | 不能简单删除，要说明利率脆弱度与行业风格高度重合，可能导致估计不精确 |

这里要注意：共线性本身不一定导致估计有偏，它主要导致标准误变大、显著性下降。这个点第三讲也强调了。

---

# 8. 第三讲知识点五：变量重要性比较

第三讲讲到，可以基于**标准化回归系数**比较不同自变量对因变量的重要程度：自变量增加一个标准差，因变量变化多少个标准差。

所以第三讲阶段我们要做一个标准化模型：

[
CAR_i^*
=======

\beta_0
+\beta_1RateVulnerability_i^*
+\gamma_1MktBeta_i^*
+\gamma_2HMLBeta_i^*
+\cdots
+u_i
]

R代码：

```r
df_std <- df
vars <- c("CAR", "RateVulnerability", "MktBeta", "SMBBeta", "HMLBeta",
          "RMWBeta", "CMABeta", "HistVol", "PreMomentum")

df_std[paste0(vars, "_z")] <- scale(df_std[vars])

m_std <- lm(CAR_z ~ RateVulnerability_z + MktBeta_z + SMBBeta_z + HMLBeta_z +
              RMWBeta_z + CMABeta_z + HistVol_z + PreMomentum_z,
            data = df_std)
```

我们要输出一张“标准化系数图”：

| 变量                | 标准化系数 | 解释          |
| ----------------- | ----: | ----------- |
| RateVulnerability |   ... | 利率脆弱度的重要性   |
| MktBeta           |   ... | 市场风险暴露的重要性  |
| HMLBeta           |   ... | 价值/成长风格的重要性 |
| HistVol           |   ... | 历史波动率的重要性   |
| PreMomentum       |   ... | 事件前动量的重要性   |

如果`RateVulnerability_z`的标准化系数绝对值最大或排在前列，我们就可以写：

> 在各解释变量统一为标准差单位后，利率脆弱度仍然是解释行业FOMC事件窗口收益的重要变量，说明其经济意义不仅体现在统计显著性上，也体现在相对解释强度上。

# 9. 第三讲知识点六：t检验、F检验和联合显著性

第三讲后半部分很强调F检验：F检验不仅可以检验整个回归方程显著性，也可以用于模型设定不足的诊断，特别是嵌套模型的比较。

我们要做三类检验。

## 9.1 单个系数t检验

核心是：

[
H_0:\beta_1=0
]

即利率脆弱度没有解释力。

报告：

* 系数；
* 标准误；
* t值；
* p值；
* 95%置信区间。

## 9.2 控制变量联合显著性F检验

比较模型0和模型2：

约束模型：

[
CAR_i=\beta_0+\beta_1RateVulnerability_i+u_i
]

非约束模型：

[
CAR_i=\beta_0+\beta_1RateVulnerability_i+\gamma X_i+u_i
]

原假设：

[
H_0:\gamma_1=\gamma_2=\cdots=\gamma_k=0
]

如果拒绝原假设，说明这些控制变量联合显著，简单模型存在设定不足问题。第三讲也明确说，两个或多个单独t检验不显著的变量，联合起来可能显著，因此不能只看单个t检验。

R代码：

```r
m0 <- lm(CAR ~ RateVulnerability_z, data = df)

m2 <- lm(CAR ~ RateVulnerability_z + MktBeta_z + SMBBeta_z + HMLBeta_z +
           RMWBeta_z + CMABeta_z + HistVol_z + PreMomentum_z,
         data = df)

anova(m0, m2)
```

## 9.3 Fama-French风格变量联合显著性

原假设：

[
H_0: \gamma_{SMB}=\gamma_{HML}=\gamma_{RMW}=\gamma_{CMA}=0
]

R代码：

```r
library(car)

linearHypothesis(m2, c("SMBBeta_z = 0",
                       "HMLBeta_z = 0",
                       "RMWBeta_z = 0",
                       "CMABeta_z = 0"))
```

这对应“风格暴露是否整体重要”。

# 10. 第三讲知识点七：虚拟变量、交互项和结构性变化

第三讲里面也有用虚拟变量和交互项检验不同总体回归模型是否存在结构变化的内容，比如不同性别总体的GPA模型，重点是看截距和斜率是否存在差异。

对应到我们的论文，就是做行业异质性：

[
CAR_i
=====

\beta_0+\beta_1RateVulnerability_i+\delta_1Tech_i+\delta_2Finance_i
+\theta_1(RateVulnerability_i\times Tech_i)
+\theta_2(RateVulnerability_i\times Finance_i)
+\gamma X_i+u_i
]

解释：

* (\delta_1)：科技行业相对于基准行业的平均CAR差异；
* (\theta_1)：科技行业的利率脆弱度斜率是否更强；
* (\beta_1+\theta_1)：科技行业中利率脆弱度对CAR的总效应。

建议分组不要太多，因为我们只有49个行业。可以先设置3个虚拟变量：

| 分组         | 含义                     |
| ---------- | ---------------------- |
| TechGrowth | 科技、软件、电子、通信、商业服务等成长型行业 |
| Finance    | 银行、保险、交易、房地产相关行业       |
| Defensive  | 公用事业、食品、医疗等防御型行业       |

R代码：

```r
m_interact <- lm(CAR ~ RateVulnerability_z * TechGrowth +
                   RateVulnerability_z * Finance +
                   RateVulnerability_z * Defensive +
                   MktBeta_z + HMLBeta_z + HistVol_z + PreMomentum_z,
                 data = df)
```

联合检验交互项：

```r
linearHypothesis(m_interact, c("RateVulnerability_z:TechGrowth = 0",
                               "RateVulnerability_z:Finance = 0",
                               "RateVulnerability_z:Defensive = 0"))
```

论文解释：

> 如果交互项联合显著，说明利率脆弱度对事件窗口收益的影响存在行业结构性差异；如果不显著，说明行业间主要是平均水平差异，而非斜率差异。

这个部分可以直接变成期末要求中的“异质性分析”。

# 11. 第三讲知识点八：模型设定不足、过度设定和误设诊断

第三讲后面有模型设定、误设和诊断，尤其是RESET检验，用来诊断是否遗漏了解释变量的非线性函数；如果模型设定正确，解释变量的非线性函数进入模型后应不显著。 讲义还提到RAINBOW检验，用来判断函数形式误设，例如房价水平模型可能存在误设，而对数模型不存在函数形式误设。

我们这里要做三件事。

## 11.1 RESET检验

R代码：

```r
library(lmtest)

resettest(m2, power = 2:3, type = "fitted")
```

解释：

* 如果不拒绝原假设：模型函数形式没有明显误设；
* 如果拒绝原假设：可能存在遗漏的非线性项或交互项。

## 11.2 加入平方项检验非线性

[
CAR_i
=====

\beta_0+\beta_1RateVulnerability_i+\beta_2RateVulnerability_i^2+\gamma X_i+u_i
]

R代码：

```r
m_quad <- lm(CAR ~ RateVulnerability_z + I(RateVulnerability_z^2) +
               MktBeta_z + HMLBeta_z + HistVol_z + PreMomentum_z,
             data = df)

anova(m2, m_quad)
```

解释：

* 如果平方项显著，说明利率脆弱度对CAR的影响不是线性的；
* 如果不显著，可以保留线性模型，更符合第三讲的基本框架。

## 11.3 过度设定控制

我们样本只有49个行业，不能无限加变量。第三讲讲到引入虚拟变量要求更大样本量。 所以我们需要控制模型复杂度：

主模型不要超过8个左右解释变量；
交互项模型作为异质性扩展，不作为主模型；
完整模型和精简模型都报告，避免老师觉得我们过度拟合。

# 13. 第三讲在论文里怎么写

建议论文实证部分这样安排：

## 5.1 从一元回归到多元回归：可观测遗漏变量的控制

写第二讲一元结果，然后指出：

> 一元模型可能遗漏行业市场风险暴露、风格暴露、历史波动率和事件前动量等因素。若这些因素既影响事件窗口收益，又与行业利率脆弱度相关，则简单OLS估计可能混入遗漏变量偏误。因此本文进一步建立多元线性回归模型。

## 5.2 多元线性回归模型设定

放主模型：

[
CAR_i
=====

\beta_0+\beta_1RateVulnerability_i+\gamma X_i+u_i
]

并解释 (\beta_1) 是“控制其他变量后的偏效应”。

## 5.3 估计结果：控制变量后的利率脆弱度效应

放M0、M1、M2回归表。

重点看：

1. (\beta_1) 是否仍为负；
2. 显著性是否保持；
3. 系数大小是否明显变化；
4. (R^2)、调整 (R^2) 是否提高；
5. 控制变量联合F检验是否显著。

## 5.4 变量重要性与共线性诊断

放标准化系数表和VIF表。

## 5.5 结构性变化与行业异质性

放虚拟变量和交互项模型。

## 5.6 模型设定诊断

放RESET、平方项、嵌套模型F检验。

# 14. 第三讲阶段的判断标准

做完这一步后，我们根据结果决定下一步论文叙事。

## 情况A：RateVulnerability仍显著为负

这是最理想的。

结论可以写：

> 在控制市场风险暴露、风格暴露、历史波动率和事件前动量后，行业利率脆弱度仍显著降低事件窗口收益，说明FOMC紧缩冲击下的行业分化不仅是一般风险因子暴露导致的，还存在独立的利率敏感性渠道。

## 情况B：RateVulnerability变小但仍为负

也很好。

结论可以写：

> 一元模型高估了利率脆弱度的影响，因为部分效应来自行业市场beta和成长风格；但在控制这些因素后，利率脆弱度仍保留负向解释力。

这体现了第三讲“控制变量后解释偏效应”的思想。

## 情况C：RateVulnerability不显著了

也不是失败，可以改写假设：

> 行业利率脆弱度的一元相关性主要由成长/价值风格、市场beta和历史波动率等可观测行业特征驱动。货币政策冲击对行业收益的影响可能并非独立的利率敏感性效应，而是通过资产定价因子暴露体现出来。

这个也很像真实研究，因为结果不是硬凑显著性。

# 15. 这一阶段最重要的提醒

单次FOMC事件的截面模型里，**不能直接加入 (Shock_t)、(VIX_t)、(MKT_t) 这种事件层面的变量**。因为在同一次事件中，它们对49个行业都是同一个数，没有截面变化，无法解释行业之间的差异。

现在能加入的是行业层面变量，比如：

[
RateVulnerability_i,\ MktBeta_i,\ HMLBeta_i,\ HistVol_i
]

等到第七讲进入“多次FOMC × 多行业”的混合截面或面板数据后，我们才可以正式加入：

[
Shock_t,\ Shock_t\times RateVulnerability_i
]

那时我们的核心模型会变成：

[
CAR_{i,t}
=========

\alpha+\beta Shock_t\times RateVulnerability_i+\gamma X_{i,t}+u_{i,t}
]

但现在第三讲阶段先不做这个。现在的任务就是把单次事件下的行业截面模型做扎实。
