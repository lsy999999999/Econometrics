对，我们先不要一上来就做“FOMC事件 × 49行业 × 多期面板”的完整模型。第一步应该严格对应第二讲：**先构造一个最简单的截面数据集，用一元线性回归检验一个最朴素的线性假设**。第二讲的核心就是从简单截面观测数据出发，设定总体模型 (y_i=\beta_0+\beta_1x_i+u_i)，重点理解线性模型、误差项 (u)、参数含义和高斯—马尔可夫假定。 期末要求里也明确要有“基准模型”，也就是先做只包含核心自变量的模型，再逐步增加控制变量、讨论内生性、异方差、机制和异质性。

## 这一步我们要做什么？

我们先做一个**单次FOMC事件下的行业截面回归**。

也就是说，不是先把所有FOMC会议都放进去，而是先选一个明显的紧缩性FOMC事件。然后把美国49个Fama-French行业组合看作49个截面观测。每个行业有一个事件窗口收益，也有一个事前估计出来的“利率敏感度”。我们检验：

> 在同一次紧缩性货币政策冲击下，事前越“怕利率上升”的行业，事件窗口收益是否越低？

这个就是最简单、最清楚的一元线性假设。

---

# 一、为什么不能直接做：行业收益 = 货币政策冲击？

因为在**单次FOMC事件截面**里，货币政策冲击对所有行业都是一样的。

比如某次FOMC会议后，2年期美债收益率上升了20个基点。那么这20个基点对49个行业都是同一个数。它在截面上没有变化，不能作为一元回归的 (x_i)。

所以第一步不能写成：

[
CAR_i=\beta_0+\beta_1 Shock+\mu_i
]

因为 (Shock) 对所有 (i) 都相同，无法解释行业之间的差异。

正确做法是：在这一轮简单截面模型里，把**行业特征**作为解释变量。最自然的行业特征就是：

> 这个行业在历史上对利率变化有多敏感。

---

# 二、第一步的数据结构

这一阶段的数据表非常简单，只有49行。

| 行业 (i)      | 事件窗口收益 (CAR_i) | 利率脆弱度 (RateVulnerability_i) |
| ----------- | -------------: | --------------------------: |
| Agriculture |            ... |                         ... |
| Food        |            ... |                         ... |
| Banks       |            ... |                         ... |
| Software    |            ... |                         ... |
| Utilities   |            ... |                         ... |
| ...         |            ... |                         ... |

每一行是一个行业组合。FOMC事件日期可以从美联储官网的FOMC会议日历、声明和纪要页面获得，美联储官网也说明FOMC通常每年召开8次定期会议。([联邦储备委员会][1]) 行业收益数据用Kenneth French Data Library的49 Industry Portfolios [Daily]，该页面提供49行业组合日度收益数据。([达特茅斯大学塔克商学院][2]) 利率数据用FRED的DGS2，也就是2年期美国国债固定期限收益率，FRED显示该序列为日度、百分比、非季调数据。([FRED][3])

---

# 三、因变量怎么构造：事件窗口收益

先不要做复杂的Fama-French异常收益。第一步我们就用最直观的事件窗口收益：

[
CAR_i^{[-1,+1]}=\sum_{\tau=-1}^{1}R_{i,t_0+\tau}
]

其中：

(i)：第 (i) 个行业；
(t_0)：FOMC公告日；
([-1,+1])：公告日前一天、公告当天、公告后一天；
(R_{i,t})：第 (i) 个行业在第 (t) 天的日收益率。

所以 (CAR_i) 的含义是：

> 某行业在FOMC公告附近三天的累计收益率。

为什么先用 ([-1,+1])？因为FOMC信息可能在公告当天和次日被市场消化，前一天也可能包含预期交易。后面稳健性检验再换成 ([0,0])、([0,+1])、([-2,+2])。

---

# 四、自变量怎么构造：行业利率脆弱度

我们需要一个在行业之间变化的变量。建议用历史数据估计每个行业对2年期美债收益率变化的敏感度。

先在FOMC事件前的一段估计窗口中，比如事件日前260个交易日到前30个交易日，估计：

[
R_{i,d}=a_i+b_i\Delta DGS2_d+e_{i,d}
]

其中：

(R_{i,d})：行业 (i) 在历史交易日 (d) 的收益率；
(\Delta DGS2_d)：当天2年期美债收益率变化；
(\hat b_i)：行业 (i) 对利率变化的历史敏感度。

如果 (\hat b_i<0)，说明历史上利率上升时，这个行业更容易下跌。为了让解释更直观，我们定义：

[
RateVulnerability_i=-\hat b_i
]

这样 (RateVulnerability_i) 越大，表示这个行业越“怕加息”或者越“怕利率上升”。

---

# 五、最简单的一元线性回归模型

这一步的基准模型就是：

[
CAR_i=\beta_0+\beta_1RateVulnerability_i+u_i
]

这就是完全对应第二讲的简单线性回归。

对应关系是：

| 第二讲模型     | 我们论文里的变量                 |
| --------- | ------------------------ |
| (y_i)     | 第 (i) 个行业的FOMC事件窗口收益     |
| (x_i)     | 第 (i) 个行业的事前利率脆弱度        |
| (\beta_0) | 当行业利率脆弱度为0时的平均事件收益       |
| (\beta_1) | 利率脆弱度每增加一个单位，事件窗口收益的平均变化 |
| (u_i)     | 除利率脆弱度以外影响行业收益的其他因素      |

我们的核心假设是：

[
H_1:\beta_1<0
]

也就是：

> 在紧缩性FOMC冲击下，利率脆弱度越高的行业，事件窗口收益越低。

这个假设有清楚的资产定价理论基础：利率上升提高贴现率，长期现金流占比较高、融资依赖较强或估值对利率更敏感的行业，价格受到的冲击更大。

---

# 六、这一阶段要特别写清楚 (u_i) 是什么

第二讲特别强调 (u) 不是垃圾桶，而是“除 (x) 之外影响 (y) 的其他因素”。讲义里说，(u) 可能来自理论不完备、内在随机性和数据欠缺。

在我们的模型里，(u_i) 包含：

行业自身市场beta；
行业成长属性；
行业杠杆率；
行业盈利预期；
FOMC当天是否有其他行业新闻；
能源价格、美元指数、信用利差等同步冲击；
行业组合收益的测量误差；
行业分类带来的粗糙性。

这一段很重要，因为它自然引出后面的第三讲：为什么要从一元回归进入多元回归。第三讲正好讲了，如果遗漏了与核心自变量相关的因素，OLS估计会有偏和不一致；可观测的遗漏变量应通过多元线性回归控制。

---

# 七、第一步我们具体跑什么结果？

先做四个东西就够了。

## 1. 描述性统计

展示49个行业的：

平均事件窗口收益；
事件窗口收益标准差；
最大值、最小值；
利率脆弱度均值和标准差。

这让老师看到你不是直接回归，而是先理解数据。

## 2. 散点图

横轴：

[
RateVulnerability_i
]

纵轴：

[
CAR_i
]

加一条OLS拟合线。

这张图非常重要，因为第二讲本质上就是“样本里的线性关系能不能代表总体里的线性关系”。如果散点图已经看不出负向关系，后面模型再复杂也会比较尴尬。

## 3. 一元OLS回归表

表格可以这样：

| 变量                |            系数 | 标准误 |  t值 |  p值 |
| ----------------- | ------------: | --: | --: | --: |
| RateVulnerability | (\hat\beta_1) | ... | ... | ... |
| Constant          | (\hat\beta_0) | ... | ... | ... |
| (N)               |            49 |     |     |     |
| (R^2)             |           ... |     |     |     |

## 4. 一段经济解释

比如如果我们得到：

[
\hat\beta_1=-0.65
]

就可以解释为：

> 在该次紧缩性FOMC事件中，行业利率脆弱度每提高一个单位，行业三日累计收益平均下降0.65个百分点。

如果我们把 (RateVulnerability_i) 标准化，那么解释更漂亮：

> 利率脆弱度提高一个标准差，行业事件窗口收益平均下降0.65个百分点。

我建议标准化一下，因为不同变量单位不好解释。

# 八、这一阶段不要过度声称“因果”

第二讲里面最关键的点是：(\beta_1) 只有在 (u) 中其他因素保持不变，或者 (u) 与 (x) 不相关时，才能解释为因果效应。

所以我们第一步论文里要写得很稳：

> 本文首先建立一元线性回归模型，考察行业利率脆弱度与FOMC事件窗口收益之间的基准关联。由于行业利率脆弱度可能与行业成长性、市场beta、融资依赖度等因素相关，简单OLS结果暂不直接解释为严格因果效应，而是作为后续多元回归、稳健性检验和机制分析的基准。

这句话很加分。它说明你知道简单回归的限制，而不是把相关关系硬说成因果关系。

---

# 九、这一阶段在论文中可以怎么写

你可以把它作为实证部分的第一小节：

## 5.1 基准线性关系：行业利率脆弱度与事件窗口收益

先写：

> 为了从最简单的经验关系出发，本文首先以单次FOMC紧缩性事件为研究对象，将Fama-French 49个行业组合视为截面观测，建立一元线性回归模型，检验事前利率脆弱度是否能够解释行业在事件窗口内的收益差异。

然后给模型：

[
CAR_i=\beta_0+\beta_1RateVulnerability_i+u_i
]

再解释：

> 其中，(CAR_i) 表示行业 (i) 在FOMC事件窗口 ([-1,+1]) 内的累计收益率；(RateVulnerability_i) 为根据事件前历史数据估计的行业利率脆弱度。若 (\beta_1<0)，说明在紧缩性货币政策冲击下，越依赖低利率环境或越对利率上升敏感的行业，市场表现越差。

最后写假设：

[
H_1:\beta_1<0
]

# 十、这一小步做完后，下一步怎么自然升级？

第一步只对应第二讲。后面我们可以这样把知识点串起来：

第二讲：一元线性回归，先看 (RateVulnerability_i) 和 (CAR_i) 的简单关系。
第三讲：加入控制变量，例如行业市场beta、历史波动率、过去收益率，做多元回归。
第四讲：检验异方差，用White/BP检验和稳健标准误。
第五讲：讨论 (RateVulnerability_i) 和 (Shock_t) 的测量误差、遗漏变量、内生性，用代理变量或替代冲击变量解决。
第七讲：把单次FOMC截面扩展为“多次FOMC × 多行业”的混合截面/面板数据。
第八讲：可选做一个二值因变量扩展，比如“行业是否跑输市场”作为0/1变量，用LPM/Logit做补充稳健性。

所以现在这一步不要贪多。我们就先完成：

> **单次FOMC事件 + 49行业截面 + 一元OLS + 散点图 + 简单解释 + 承认 (u) 里有遗漏因素。**

这就是最干净的起点。
