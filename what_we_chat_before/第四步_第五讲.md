## 一、这一阶段的总目标

我们现在不换研究问题，仍然围绕：

**货币政策冲击是否会使利率脆弱行业在 FOMC 事件窗口中出现更低的超常收益？**

# 二、Step 5 的具体研究设计

## Step 5.1 先写清楚：为什么这里可能有内生性？

我们要在论文里单独开一个小节：

**“5.1 内生性来源：遗漏变量与测量误差”**

这里不要直接说“我们有内生性”，而是说“本研究存在以下潜在威胁”。

### 1. 不可观测遗漏变量

我们的核心解释变量是：

[
RateVulnerability_i
]

它表示行业对利率变化的脆弱程度。问题是：某些不可观测行业特征可能同时影响利率脆弱度和 FOMC 事件收益。

例如：

* 行业现金流久期；
* 行业成长性；
* 行业融资约束；
* 行业资产久期；
* 投资者对行业的宏观敏感性预期；
* 行业避险属性；
* 行业在紧缩周期中的风险暴露。

这些变量如果进入误差项，并且又与 `RateVulnerability_z` 相关，就会导致 OLS 估计不一致。第五讲讲义里就是这个逻辑：现实中存在大量影响因变量且与 x 相关、但无法观测的控制变量；忽略这些变量会导致模型设定不足，并且当不可观测变量 q 与核心自变量相关时会导致不一致估计。

论文里可以这样写：

> 尽管本文已经控制市场 beta、历史波动率、行业因子暴露等可观测特征，但仍可能存在不可观测的行业现金流久期、融资约束程度或投资者预期差异。这些因素既可能影响行业的利率脆弱度，也可能直接影响 FOMC 事件窗口中的资产价格反应，因此构成潜在遗漏变量偏误。

### 2. 测量误差

我们的 `RateVulnerability_z` 本质上是估计出来的，不是直接观测到的真实“利率脆弱度”。所以存在自变量测量误差。

第五讲讲义里说，自变量测量误差在经典变量误差假定下会导致解释变量内生，OLS 估计出现向零偏误，而且还会增大估计量方差。这对我们非常有用。

论文里可以写：

> 如果行业真实利率脆弱度为 (RateVulnerability_i^*)，而本文观测到的是带有估计误差的 (RateVulnerability_i)，则核心解释变量存在测量误差。若该误差满足经典变量误差假定，OLS 系数可能向零偏误。因此，若本文仍然发现显著负向关系，则从测量误差角度看，实际效应可能不弱于基准估计。

这个点很漂亮，因为它能把第五讲理论和我们的结果结合起来。

# 三、实证部分怎么做

## Step 5.2 可观测遗漏变量：扩展控制变量模型

先做最稳的办法：把能观察到的遗漏变量尽量控制进去。

我们构造模型：

[
CAR_i = \alpha + \beta RateVulnerability_i + \gamma'Controls_i + u_i
]

然后逐步加入控制变量：

| 模型 | 目的        | 控制变量                     |
| -- | --------- | ------------------------ |
| M1 | 基准 OLS    | 只放 `RateVulnerability_z` |
| M2 | 第三讲扩展模型   | 加入市场 beta、历史波动率、FF 因子暴露等 |
| M3 | 第五讲代理变量模型 | 加入不可观测行业特征的代理变量          |
| M4 | 测量误差稳健模型  | 替换 CAR 或替换脆弱度变量          |
| M5 | IV / 2SLS | 使用工具变量处理潜在内生性            |

我们已经有 M2 和异方差处理结果了，所以 Step 5 重点是 M3-M5。

---

## Step 5.3 代理变量法：为不可观测行业特征找 proxy

第五讲讲义对代理变量的定义是：某种与研究中试图控制但无法观测的变量相关的变量；例如用 IQ 代理能力，并且代理变量不是简单替换，而要讨论它在什么条件下能使估计一致。

我们这里可以把不可观测的 (q_i) 理解为：

> 行业层面的“长期利率敏感性 / 现金流久期 / 成长属性 / 宏观风险暴露”。

可使用的代理变量包括：

| 不可观测因素 (q_i) | 可用代理变量 z                             | 经济含义             |
| ------------ | ------------------------------------ | ---------------- |
| 行业成长性 / 久期属性 | HML loading、CMA loading、RMW loading  | 成长型、投资型、盈利型特征    |
| 行业系统性风险      | Market beta                          | 行业对市场冲击的敏感性      |
| 行业不确定性       | HistVol                              | 行业收益波动率          |
| 行业事件惯性       | pre-event return / pre-CAR           | 事件前价格反应或预期调整     |
| 行业避险属性       | Gold dummy 或 commodity-related dummy | 避险行业可能在紧缩事件中表现不同 |

代理变量模型可以写成：

[
CAR_i = \alpha + \beta RateVulnerability_i + \theta Proxy_i + \gamma'Controls_i + u_i
]

重点不是只看 proxy 显不显著，而是看：

1. 加入代理变量后，(\beta) 是否仍然为负；
2. (\beta) 的绝对值是否大幅变化；
3. 显著性是否消失；
4. 结果是否由某一个 proxy 驱动。

如果加入 proxy 后核心系数仍然稳定，就可以写：

> 这说明基准结果并非完全由行业成长性、历史波动率或市场风险暴露等可观测代理因素驱动。

讲义里还说，好的代理变量需要满足两个核心条件：一是控制 x 和 q 后，代理变量 z 不应直接影响 y；二是控制 z 后，q 与 x 零相关，从而保证 (\beta) 估计一致。论文里不需要证明得很数学，但要写出这个逻辑。

---

## Step 5.4 测量误差分析：替换 y 和替换 x

这一块非常适合我们，因为事件研究里的 CAR 和利率脆弱度都可能有测量误差。

### 1. 因变量 CAR 的测量误差

因变量测量误差通常不会使 OLS 不一致，但会增大误差项方差，使估计量方差变大。第五讲讲义明确说，如果因变量测量误差与解释变量无关，依据测量值建模通常 OLS 一致，但会增大估计量方差。

所以我们做：

| 替换因变量         | 含义           |
| ------------- | ------------ |
| `CAR_3`       | 主结果，三日事件窗口   |
| `CAR_1`       | 当日或一日窗口      |
| `CAR_5`       | 五日窗口         |
| `AR_0`        | FOMC 当日超常收益  |
| `CAR_ex_gold` | 剔除 Gold 后的结果 |

论文解释：

> 若不同事件窗口下 `RateVulnerability_z` 仍然保持负向，说明结论并非由 CAR 度量方式驱动。

### 2. 自变量 RateVulnerability 的测量误差

对自变量测量误差，讲义说经典变量误差下 OLS 存在向零的不一致性偏误，并会增大估计量方差。所以我们要替换核心解释变量：

| 替换自变量                                  | 目的            |
| -------------------------------------- | ------------- |
| 原始 `RateVulnerability_z`               | 主指标           |
| 使用更长估计窗口构造的 `RateVulnerability_long_z` | 降低估计噪声        |
| 使用不同利率期限构造的 vulnerability              | 检查结果是否依赖短端利率  |
| Winsorized vulnerability               | 排除极端行业影响      |
| Leave-one-out vulnerability            | 检查单个事件或行业是否驱动 |

如果替换后仍然负向，就可以说：

> 核心结论对利率脆弱度的度量方式不敏感。

# 四、Step 5.5 工具变量法与 2SLS：做，但要谨慎解释

这一部分是第五讲最重要、也最容易被老师看出来有没有真正理解的地方。

讲义里强调，工具变量需要满足三点：第一，与内生解释变量相关，即工具相关性；第二，与误差项不相关，即工具外生性；第三，满足排除性约束，即工具变量只能通过内生变量影响被解释变量，不能有其他直接路径。

所以我们不能随便找一个变量就说它是 IV。我们要把这部分写得谨慎一点。

## 1. 候选工具变量设计

我建议做一个 **探索性 IV / 2SLS 分析**，不把它作为主结论，而是作为内生性稳健性检验。

候选工具变量可以考虑：

### IV 方案 A：预样本利率敏感性工具

构造：

[
Z_i = PreSampleRateSensitivity_i
]

也就是用事件窗口之前较长历史区间中，行业组合收益对国债收益率变化的敏感性作为工具变量。

逻辑是：

* 相关性：长期历史利率敏感性应该与本研究中的 `RateVulnerability_z` 高度相关；
* 外生性：它来自事件窗口之前，不直接由本次 FOMC 事件收益决定；
* 排除性约束：它影响 FOMC CAR 的主要渠道应当是行业利率脆弱度。

但是要承认局限：

> 该工具变量可能仍然捕捉行业长期风险属性，因此排除性约束并非完全可检验。本文将其作为探索性 2SLS，而非唯一识别依据。

这句话非常重要，会显得你不是机械套模型。

### IV 方案 B：不同期限利率敏感性作为多工具变量

比如：

* `Sensitivity_2Y_pre`
* `Sensitivity_10Y_pre`

如果两个工具变量都与 `RateVulnerability_z` 相关，就可以做过度识别检验。但要注意第五讲说，没有过度识别时，工具外生性检验没有意义。所以：

* 只有一个 IV、一个内生变量：exactly identified，不能做有效的过度识别检验；
* 两个或更多 IV、一个内生变量：overidentified，可以做 Sargan/Hansen 检验。

## 2. 第一阶段：检验工具相关性

第一阶段模型：

[
RateVulnerability_i
===================

\pi_0 + \pi_1 Z_i + \pi_2 Controls_i + v_i
]

重点报告：

* (\pi_1) 的符号和显著性；
* 第一阶段 F 统计量；
* partial (R^2)；
* 是否存在弱工具变量问题。

讲义里说，考察一个变量是否可以作为 IV 时，工具外生性通常没有有效技术手段，主要依据经济问题判断；工具相关性则可以通过估计 x 对 z 的回归来检验，如果拒绝原假设，就认为 z 与 x 相关。这一句可以直接变成论文里的方法说明。

## 3. 第二阶段：估计 2SLS

第二阶段模型：

[
CAR_i
=====

\alpha + \beta \widehat{RateVulnerability}_i + \gamma'Controls_i + u_i
]

R 里用：

```r
library(AER)
library(sandwich)
library(lmtest)

iv_m1 <- ivreg(
  CAR_3 ~ RateVulnerability_z + controls |
    Z_pre_rate_sensitivity + controls,
  data = df
)

coeftest(iv_m1, vcov = vcovHC(iv_m1, type = "HC3"))
summary(iv_m1, diagnostics = TRUE)
```

如果有两个工具变量：

```r
iv_m2 <- ivreg(
  CAR_3 ~ RateVulnerability_z + controls |
    Z_sens_2y_pre + Z_sens_10y_pre + controls,
  data = df
)

summary(iv_m2, diagnostics = TRUE)
coeftest(iv_m2, vcov = vcovHC(iv_m2, type = "HC3"))
```

第五讲也讲到，当每个内生变量只有单个 IV 时，2SLS 等同于 IV 估计；第一阶段先用工具变量预测内生变量，第二阶段再用预测值估计结构方程。多工具变量时，两阶段最小二乘的思路是用外生变量的线性组合寻找与内生变量最相关的部分。

## 4. 结果怎么判断

我们主要看四种情况：

| 结果          | 解释                              |
| ----------- | ------------------------------- |
| IV 系数仍为负且显著 | 最强，说明内生性处理后结论仍支持 H1             |
| IV 系数为负但不显著 | 可以接受，可能因为 IV 方差更大、样本只有 49 个行业   |
| IV 系数方向反转   | 要谨慎，可能说明 OLS 结果受内生性影响，也可能是弱工具问题 |
| 第一阶段很弱      | 不强调 IV 结论，只把它放入附录或作为探索性分析       |

讲义里也提醒，IV 的渐近方差通常大于 OLS，工具变量与内生变量弱相关时，IV 方差会比 OLS 大很多；工具相关性越强，IV 方差越小。所以如果 2SLS 标准误变大，我们不能说“模型坏了”，而要解释为 IV 估计本来更依赖工具强度。

# 五、Step 5.6 内生性检验：DWH / Hausman 思路

如果用 `ivreg`，可以输出 Wu-Hausman 检验。这里的逻辑是：

* 原假设：`RateVulnerability_z` 可以视为外生；
* 拒绝原假设：OLS 可能不一致，IV 更合适；
* 不拒绝原假设：没有充分证据认为 OLS 存在内生性问题。

但我们要注意：不拒绝不是证明没有内生性，尤其我们样本量小。

论文可以这样写：

> Hausman 型内生性检验没有提供充分证据拒绝核心解释变量外生性的原假设。因此，在本文样本下，OLS 结果仍可作为主要基准；不过考虑到不可观测行业属性仍可能存在，本文进一步报告 2SLS 作为稳健性分析。

# 六、机制分析怎么和第五讲结合

期末要求里提到研究假设可以包括直接影响、中介影响等，论文还应包括影响机制分析。我们这里不一定要做复杂中介模型，可以做“机制型异质性”。

建议设一个机制假设：

**H2：利率脆弱度的负向影响在高久期 / 高成长 / 高波动行业中更强。**

模型：

[
CAR_i
=====

\alpha
+
\beta_1 RateVulnerability_i
+
\beta_2 HighDuration_i
+
\beta_3 RateVulnerability_i \times HighDuration_i
+
\gamma'Controls_i
+
u_i
]

其中 `HighDuration_i` 可以用以下 proxy 定义：

* 高 HML 负暴露行业；
* 高 CMA / RMW 特征行业；
* 高历史波动率行业；
* 高市场 beta 行业；
* 高利率敏感性行业。

核心看 (\beta_3)：

* 如果 (\beta_3 < 0)，说明利率脆弱度的负面影响在高久期/高成长/高风险行业更强；
* 这可以解释为“贴现率渠道”或“风险重估渠道”。

这一部分既能体现机制，又能把第五讲的 proxy 思想用进去。
